# 🎬 Netflix Clone (HTML & CSS)

A responsive front-end clone of the Netflix homepage, built as a minor project to practice layout design, styling, and UI recreation using pure HTML and CSS.

> ⚠️ **Disclaimer:** This is an unofficial, non-commercial student project created purely for learning and portfolio purposes. It is **not affiliated with, endorsed by, or connected to Netflix, Inc.** in any way. All Netflix trademarks and content belong to their respective owners.

---

## 📌 About the Project

This project recreates the look and feel of Netflix's landing page, including:

- A Netflix-inspired **navigation bar**
- A **hero/banner section**
- **Movie/show sections** with card layouts
- Responsive, modern styling to mimic the original design

The goal was to strengthen core front-end fundamentals — semantic HTML structure, CSS layout techniques (Flexbox/Grid), and responsive design — without using any frameworks or libraries.

---

## 🛠️ Built With

- **HTML5** — page structure and content
- **CSS3** — styling, layout, and responsiveness

## 🚀 Getting Started

To run this project locally:

1. Clone the repository
   ```bash
   git clone https://github.com/tanmay2007-pirate/Netflix-clone-HTML-CSS-minor-project.git
   ```
2. Navigate into the project folder
   ```bash
   cd Netflix-clone-HTML-CSS-minor-project
   ```
3. Open `index.html` in your browser

No build tools or dependencies required — it's pure HTML/CSS.
